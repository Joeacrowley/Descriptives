3.2 Individual functions

The following statistics are currently catered for: mean, median and sum for numeric outcomes, percentage and count for categorical ones.

Potential additions: max, min, SD, IQR and other percentile values.

These are the functin names that calculate these.

Weighted functions:
* weighted_mean,
* weighted_median,
* weighted_sum,
* weighted_perc,
* weighted_count.

Unweighted functions:
* unweighted_mean,
* unweighted_median,
* unweighted_sum,
* unweighted_perc,
* unweighted_count.

An unweighted count is always calculated, stored in unweighted_n. When using unweighted_count it is also stored in estimate (it is duplicated).

3.2.1 Arguments

The functions above have the same arguments:

  • data - a dataframe for unweighted functions, a srvyr object for weighted functions. Unweighted functions will also accept srvyr objects.
  • outcomes - vector of otucome variable names.
  • predictors - list of predictor variable names. Each element is a vector and can be of length > 1 to produce nested tables.
  • conf - either “se” for standard errors or “ci” for confidence intervals.
  • base - the output of the base_information function, a sort of data dictionary of base descriptions (requires manual specification).

Data output structure:- a data frame, column names are…

  • cross_break - predictor variable names separated by ’ X ’. If not predictor then “Total”.
  • outcome - outcome variable name
  • o_lab - outcome variable label
  • o_cat - outcome variable levels, or duplicate of value in stat for numeric statistics.
  • predictor, p_lab and p_cat - same interpretation as for outcomes, with addition of numbers to differentiate mutliple predictors, predictor1 for the first predictor and so on.
  • stat - contains the statistic definition.
  • estimate, contains the statistics.
  • estimate_se for standard error.
  • estimate_ci present when confidence intervals calculated, but not really used at any point.
  • base - unweighted base size for statistics.
  • base_description - the output of create_bases for that row’s selection of predictor and outcome variables.
  • unweighted_n - cell count.

The values of stat can be:

  • “mean”
  • “median”
  • “sum”
  • “perc”
  • “count”
  • “w_mean”
  • “w_median”
  • “w_sum”
  • “w_perc”
  • “w_count”


3.3 Main supporting functions

3.3.1 Base descriptions

Consists of three functions. base_information collects a set of base descriptions linked to variable names. create_bases selects a set of those bases for a particular combination of variables used in a table, and saves them in the output in the base_description column. prepare_base_for_table then puts it in a semi-readable format for a table.

base_information takes a general base description that applies to most variables and a named character vector of specific descriptions for any that differ.

var_descriptions <- rep("Self-completion questionnaire, asked of a random sub-set of respondents", 6)
names(var_descriptions) <- c("leftrigh", "welfare2", "libauth", "libauth2", "leftrigh2", "welfare3")

base_info <- base_information(
  data = df2,
  general_base = "Asked of all respondents",
  specific_bases = var_descriptions
)

3.3.2 Median support functions

The median requires separate handling for standard errors and confidence intervals. Two functions support unweighted_median internally:

  • grouped_medianse (Scripts/grouped_medianse.R) — calculates the standard error of the median within groups using wrappedtools::medianse.
  • grouped_medianci (Scripts/grouped_medianci.R) — calculates bootstrap confidence intervals around the median within groups using wrappedtools::median_cl_boot. Subsets with five or fewer observations are skipped.

These exist because SE and CI for medians cannot be derived analytically in the same way as for means.

3.3.3 Significance testing

Consists of four functions, one for each combination of weighted/unweighted and numeric/categorical outcome: unweighted_test_numeric_by_cat, weighted_test_numeric_by_cat, unweighted_test_cat_by_cat, weighted_test_cat_by_cat. These are wrapped by return_pvalues, which selects the appropriate function based on the data and outcome type, and map_return_p_values, which applies it across multiple outcomes and predictors. The results are joined into the main output by calc_stats when pval is not NULL and there is a single predictor variable. Where predictors are nested (more than one variable per predictor element), no significance test is run — no method is currently available for that case.

3.3.4 Multicodes

This checks to see if there is a common stem among some of the variables, which must be the case in both variable and variable labels. If there is, it reduces the variable names to that common stem and splits the variable label in two, taking the common stem to become the new variable label and placing the unique parts in the position of categories, over-writing ‘yes’. The ‘no’ responses are then filtered out. This is only done where all variables with the common stem also have the same base size. The result is an output that in the data frame appears to relate to a single variable and can afterwards be treated as one. It also includes a step to combine their base labels into a single label - really these should all be the same anyway.


3.3.5 Utility functions

A small set of functions handle internal plumbing and are not called directly by users.

  • source_folder_r — sources all .R files in a folder in one call. Used in the set up chunk to load all scripts at once.
  • write_function — writes a function from the environment to a .R file in the Scripts folder. Used during development to keep scripts in sync with the QMD files.
  • manage_predictors — previously used to allow different predictor sets to be passed for different outcomes. That feature was dropped as unnecessary and not useful in practice. The function remains in the Scripts folder but is no longer called by calc_stats.
  • common_prefix — extracts the longest common character prefix from a vector of strings. Used by the multicode detection logic to identify variable name stems.
  • list_depth, vars_exist, check_all_factors, outcomes_not_in_predictors — input validation helpers called by calc_stats before any calculations run.

3.4 A wrapper - calc_stats

calc_stats is the main function intended for day-to-day use. It dispatches to the individual statistic functions based on the outcome variable type and the statistics argument, runs each outcome against each predictor, and combines everything into a single data frame. Whether to use weighted or unweighted functions is determined automatically: if a srvyr survey object is passed to data, weighted functions are used for weighted statistics; if a plain data frame is passed, only unweighted statistics are available.

3.4.1 Arguments

  • data - a plain data frame or a srvyr survey object.
  • outcomes - character vector of outcome variable names.
  • predictors - a list, where each element is a character vector of predictor variable names. A vector of length > 1 produces a nested breakdown. If NULL, an overall total is returned.
  • statistics - character vector specifying which statistics to calculate. Defaults to c("count", "mean"). Each statistic is only applied to appropriate variable types — numeric statistics are skipped for factor outcomes and vice versa. Allowed values are: “mean”, “median”, “sum”, “perc”, “count”, “w_mean”, “w_median”, “w_sum”, “w_perc”, “w_count”.
  • conf - either “se” for standard errors or “ci” for confidence intervals. If NULL, neither is calculated.
  • base - the output of base_information. If NULL, base descriptions are omitted.
  • pval - if not NULL, p-values are computed and joined to the output. Only applies where there is a single predictor variable; nested predictors are silently skipped. No method is currently available for nested predictors.
  • multicode - if TRUE (the default), multicode detection and collapsing is applied to the output.

3.4.2 Data output structure

The same as for individual statistic functions, with two additions:

  • p_method - the significance test used.
  • p_value - the resulting p-value. NA where no test was run.

3.5 Methodological decisions requiring sign-off

The following choices are embedded in the code and require review. The relevant script is noted for each.

1. Significance test selection for numeric outcomes (unweighted)
Scripts/unweighted_test_numeric_by_cat.R
Shapiro-Wilk is run on the residuals of a linear model. If p < 0.05, Kruskal-Wallis is used; otherwise Welch’s ANOVA. The threshold and the choice of tests are both decisions that could reasonably be made differently.

2. Significance test selection for numeric outcomes (weighted)
Scripts/weighted_test_numeric_by_cat.R
Same logic using survey-aware equivalents: survey::svyranktest in place of Kruskal-Wallis, and survey::regTermTest (Wald test) in place of Welch’s ANOVA.

3. Significance test for categorical outcomes (unweighted)
Scripts/unweighted_test_cat_by_cat.R
Chi-square test used in all cases. No fallback for sparse cells.

4. Significance test for categorical outcomes (weighted)
Scripts/weighted_test_cat_by_cat.R
Adjusted Wald test (svychisq with statistic = "adjWald") used in place of standard chi-square.

5. Multicode collapsing
Scripts/convert_multicodes.R
Variables sharing a common stem in both name and label are automatically identified and treated as a single variable. Only “Yes” responses are retained; “No” responses are dropped. The assumption is that all variables in a multicode set share the same base size.
